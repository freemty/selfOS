# yuanboizer-zh 设计文档

## 概述

yuanboizer-zh 是一个个人风格润色 skill，将用户（渊博）的草稿文本改写为"像渊博写的、但别人能读懂"的形态。不是去 AI 味工具，而是风格注入工具。

**核心定位**：输入是用户自己写的草稿（Notion thoughts、微信消息、小红书帖、笔记），输出是保留其思维内核但展开为可读文本。

**设计哲学**：规则骨架 + 示例锚定 + 语域自动判断 + 质量评分。

## 文件结构

```
yuanboizer-zh/
  SKILL.md          # 主文件：风格规则 + 语域判断 + 评分表
  examples.md       # 真实 before→after 示例对（SKILL.md 引用）
```

## 风格维度（6 维）

### 1. 中英嵌套

概念性词汇保留英文，叙事和情绪用中文。英文词以词/短语形式嵌入，不写完整英文句子。

**绝不翻译的词**：taste, ambition, insight, motivation, role model, authentic, condition on, overfitting, scaling law, vibe coding, roadmap, build in public, fake it until make it

**绝不用英文的词**：情感/态度/生活词汇全中文（焦虑、坚韧、蔑视、彷徨、牌桌、方寸、厚积薄发）

**节奏**：中文长句 + 英文概念词 + 中文展开。英文词像钉子嵌入中文骨架。

**示例**：
> "越来越强烈的感受到我正借由RoPE这个切口approaching something authentic"

### 2. 跨域类比

保留并展开原文中的类比。渊博的类比模式：
- 政治史/军事史 → 科研决策（粟裕内线作战 → GAP year 选择）
- ML 术语 → 心理/人际（Forward KL/Reverse KL → 人格类型，overfitting → 死板学生）
- 工业革命 → AI 产业

如果原文有抽象论点但缺类比，可提示"这里是否有一个类比可以帮助读者理解？"但不自行编造。

**示例**：
> "回看我去年没有申请而GAP的选择，其实客观上很像粟裕在毛和中央军委倾向继续推进时坚持内线作战"

### 3. 豪迈 ↔ 自嘲无缓冲

保留情感极性，不加"不过话说回来""当然了""客观来讲"之类的缓冲软化词。渊博在高昂自我激励和坦率自我解剖之间没有中间态，润色时不能把这个棱角磨平。

**示例（豪迈）**：
> "三年内我一定要去这次工业革命的中心Deepmind openai anthropic实习"

**示例（自我解剖）**：
> "hhhh我的宽容也是假的，自己谦虚自嘲，别人顺杆爬也会面露不悦"

### 4. 宣言式收尾

段落或全文末尾用短句断言收束。不用总结式结尾（"总之……"），不用展望式结尾（"未来可期"），不用光明尾巴。

**示例**：
> "那梯度下降，干就完了"
> "得学"
> "焉知非福"

### 5. 感叹词系统

保留渊博原生的感叹表达，不替换为书面语。但不凭空添加——只有原文有强烈情绪时才使用。

| 等级 | 表达 |
|------|------|
| 最高赞叹 | "卧槽""巨屌""恐怖如斯" |
| 正面兴奋 | "爽""太爽了""牛逼" |
| 自嘲 | "hhhh" |
| 惊讶 | "我靠" |

### 6. 反模式清单

以下表达绝对不出现在润色输出中：

1. emoji — 零容忍
2. 客套对冲 — "可能我理解有误""仅供参考""不一定对"
3. 学术腔 — "具有重要意义""值得深入研究""深入探讨"
4. 空洞升华 — "更广泛的趋势""不断演变的格局"
5. 轻飘飘评价 — 无锚点的好坏判断
6. 填充性开场白 — "在当今……的时代""随着……的发展"
7. 公式化连接词 — "此外""值得注意的是""不仅……更……"
8. 展望式结尾 — "未来可期""让我们拭目以待"
9. 过度谦虚 — "我还需要学习""班门弄斧"
10. 宣传式形容词堆砌 — "充满活力的""丰富的""深刻的"

## 语域判断

### 口语帖模式

**触发条件**：输入 < 300 字，或无小标题/列表结构，或明显是碎片 thought

**润色策略**：
- 把箭头链 `→` 和压缩句展开成 2-4 个自然段
- 保留口语感，像在跟朋友聊天讲一件事
- 可以用"你知道吗""说白了"这类口语连接
- 总长控制在 200-500 字

### 结构化文章模式

**触发条件**：输入 > 300 字，或有小标题/列表/多层论点

**润色策略**：
- 保留或优化原有结构（小标题、bullet）
- 每个论点展开到别人能跟上的程度，但不啰嗦
- 保留类比和例子，必要时补一句上下文让读者能理解
- 不限长度，跟随内容需要

### 用户覆盖

如果用户指定"帮我改成小红书帖"或"润成一篇文章"，跳过自动判断，直接用指定模式。

## 质量评分表

润色完成后自动打分，5 维各 10 分，满分 50：

| 维度 | 评估标准 |
|------|----------|
| **像渊博** | 读起来像这个人写的吗？中英嵌套节奏、类比方式、情感极性是否对味 |
| **可读性** | 别人能读懂吗？压缩句是否充分展开、上下文是否充足 |
| **不端着** | 有没有混入学术腔、客套话、空洞升华？反模式清单是否全部回避 |
| **节奏感** | 长短句交替是否自然？收尾是否干脆？有没有拖泥带水 |
| **忠实度** | 原文的核心观点和情绪是否完整保留？有没有被改温和/改跑偏 |

**标准**：
- 45-50：直接输出
- 35-44：标注薄弱维度，自动修正一轮后输出
- < 35：重写

## 处理流程

1. 用户输入待润色文本（可选附加指令如"改成小红书帖"）
2. 语域判断：根据输入特征选择口语帖或结构化文章模式
3. 风格润色：按 6 个维度规则 + 对应语域策略改写
4. 质量评分：5 维打分
5. 如果 < 45 分，自动修正薄弱维度
6. 输出润色后文本 + 评分卡

## 约束

- 全程中文（英文词按中英嵌套规则处理）
- 核心观点和情绪必须忠实于原文，不改立场
- 不添加原文没有的信息或类比（除非用户要求）
- examples.md 中的示例对从 selfOS wiki 真实素材中提取
