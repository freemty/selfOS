# Academic Writing Style

Auto-apply these rules when writing or polishing English prose for academic contexts: papers, grants, design docs, research emails, README prose.

## Contract

Improve expression without changing evidence. Never invent citations, numbers, experiments, author intent, or stronger conclusions. Preserve `unsourced`, uncertainty, limitation, and provenance labels even when they make the prose less smooth.

## Scope

**In scope**: API docs, design docs, research papers, grant proposals, READMEs, runbooks, technical blog posts, postmortems, issue reports, conference rebuttals.

**Out of scope**: Fiction, poetry, marketing copy, casual chat, non-English prose.

## Style Reference

Read `references/style-rules.md` before drafting or revising. It contains the canonical prose rules and LLM-specific failure patterns; do not reproduce it in project instructions.

## How to Apply

1. **During drafting**: prioritize concrete terms, concise sentences, and cited claims.
2. **During revision**: Scan each paragraph for violations. Fix the highest-severity ones first.
3. **Severity order**: reader context and evidence fidelity are critical; needless words and overclaiming come next.

## Escape Hatch

If following a rule makes the prose worse for the specific audience and context, break it — but do so consciously, not by default.
